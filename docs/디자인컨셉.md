## 4.1 정체성 요약

- **한 문장 정체성**: 잊힌 사이트들이 보내오는 전문(電文)을 받아, 매일 한 장의 판면으로 조판해 주는 나만의 외신 데스크.
- **핵심 감정/분위기**: 통제감, 속도, 놓치지 않는다는 안도. 장식이 아니라 **활자와 괘선**이 질서를 만든다.
- **시각적 방향**: 신문지처럼 약간 누런 종이 위에 검은 잉크로 인쇄된 조밀한 목록. 새로 들어온 소식에는 편집자가 빨간 교정펜으로 표시한 것 같은 표식이 붙는다. 시간과 출처는 작고 흐린 숫자 정렬 글씨로 찍힌다. 밤에는 야간 편집국의 어두운 화면에 호박색 글씨로 바뀐다.

## 4.2 구체적 디자인 결정

### 색상 팔레트

| 토큰 | 라이트 | 다크 | 역할과 이유 |
|---|---|---|---|
| `--paper` | `#F3EFE4` | `#14130F` | 바탕. 흰색이 아니라 **신문 용지색**. 장시간 훑어도 눈이 덜 피로하다. 다크는 야간 편집국의 먹빛. |
| `--paper-2` | `#E9E3D3` | `#1D1B16` | 좌측 분류함·우측 패널 바탕. 판면(중앙)과 구분되는 **서랍** 느낌. |
| `--ink` | `#1B1A17` | `#E6E0D0` | 본문 활자. 순수 검정이 아닌 **인쇄 잉크**. |
| `--ink-2` | `#5E584B` | `#A39C8B` | 메타 정보(출처, 시각, 필드). 한 단계 물러난 활자. |
| `--ink-read` | `#9A9384` | `#6A6457` | **읽은 항목**. 잉크가 바랜 듯 흐려져 안읽음과 즉시 구별된다. |
| `--rule` | `#CFC6B0` | `#34312A` | 괘선. 카드 대신 **선으로 구획**한다. |
| `--red` | `#B8321F` | `#E0674F` | **교정 빨강**. 새 글 표식, "지난 방문 이후" 구분선, 안읽음 수. 오직 "새것"에만 쓴다. |
| `--amber` | `#9A6A12` | `#E3A83B` | **키워드 알림** 강조. 형광펜으로 그은 줄. 다크 모드에선 야간 모니터의 호박색. |
| `--blue` | `#1F4E79` | `#7FA7CF` | 링크·선택 커서. 전통 신문의 청색 교정 잉크. 선택 행 좌측 막대에 사용. |
| `--warn` | `#8A5A00` | `#D69A2E` | 소스 `주의` 상태. |
| `--fail` | `#7A1F1F` | `#D0605A` | 소스 `실패` 상태. |

색 사용 원칙: **빨강은 새것, 호박색은 내가 찾던 것, 파랑은 지금 보고 있는 것.** 이 세 가지 외에는 잉크 농도만으로 위계를 만든다.

### 타이포그래피

**맑은 고딕(`Malgun Gothic`) 하나로 통일한다. 명조체(serif)는 어떤 경우에도 사용하지 않는다.** (개발자 지시)

| 용도 | 폰트 | 이유 |
|---|---|---|
| 전체 (워드마크, 제목, 본문, 메타, 수치) | **맑은 고딕** → `Apple SD Gothic Neo` → `sans-serif` | Windows 기본 탑재 글꼴이라 웹폰트를 내려받지 않아 첫 화면이 빠르다. 조밀한 한글 목록에서도 잘 읽힌다. |
| 추출 명세 JSON 등 코드 블록만 | `Consolas`, `D2Coding`, `monospace` | 들여쓰기 정렬이 필요한 코드 표시에 한해 예외적으로 쓴다. |

- 위계는 글꼴 종류가 아니라 **굵기(400/700)와 크기**로 만든다.
- 시각·건수·D-day 같은 숫자에는 `font-variant-numeric: tabular-nums`를 적용해, 숫자 폭을 맞추고 세로로 정렬되게 한다.
- CSS 토큰 `--font-mono`는 이름만 남겨두고 값은 맑은 고딕이다. 메타 정보용 역할 구분으로만 쓴다.

크기 체계(px): 11(메타) / 13(목록 제목·UI 기본) / 15(상세 제목) / 20(섹션 머리) / 28(워드마크). 목록은 13px에 줄높이 1.45로 **조밀하게**.

### 주요 형태/레이아웃

- **모서리 반경 0.** 모든 구획은 1px 괘선. 그림자 없음. 종이 위의 인쇄물은 둥글지도 뜨지도 않는다.
- **3단 데스크 그리드**: 기본값 `좌 260px | 중앙 가변(최소 480px) | 우 400px`. 1920px 이상에서는 우측 기본값이 480px이다. 1280px 미만에서는 우측 패널이 중앙 위에 겹쳐 열린다.
- **분할 패널 크기 조절**: 모든 좌우 분할 화면은 경계선(1px 괘선, 잡는 영역 6px)을 드래그해 폭을 바꾼다. 경계선에 마우스를 올리거나 드래그하는 동안 파랑으로 표시하고, 더블클릭하면 기본값으로 돌아간다. 키보드 ←/→로 16px씩 조절하며, 사용자별 폭은 브라우저에 기억한다. 패널마다 최소·최대 폭을 둔다.
- **머리띠(Masthead)**: 상단 44px. 좌측 워드마크 `myportal` (맑은 고딕 굵게), 가운데 오늘 날짜를 신문 발행일 형식으로(`2026년 9월 18일 금요일 · 조간`), 우측 수신 상태(`최근 수집 07:12 · 소스 42 · 주의 2`)와 계정. 둥근 아바타 없이 이니셜 사각 도장.
- **판면 괘선**: 섹션 머리 아래는 **이중 괘선**(2px + 1px), 항목 사이는 단일 1px 괘선. 신문 조판에서 가져온 위계.

### 핵심 컴포넌트

| 컴포넌트 | 형태 |
|---|---|
| 목록 행 | 한 줄 구성: `[새 표식] 제목 ········ 출처 · 시각`. 둘째 줄(보통 밀도)에 필드 메타 최대 3개를 `필드명 값` 쌍으로 작은 글씨로 표기. 카드 아님. |
| 새 글 표식 | 행 왼쪽의 **빨간 세로 괘선 3px**. 읽으면 사라지고 활자는 `--ink-read`로 바랜다 (200ms 전환). |
| 지난 방문 구분선 | 빨간 1px 선 위에 작은 라벨 `── 지난 방문 09.17 22:10 이후 47건 ──`. |
| 키워드 강조 | 해당 단어에 형광펜처럼 호박색 반투명 배경 밑줄. 행 오른쪽 끝에 규칙 이름 태그. |
| 이야기 묶음 | 대표 행 아래 `+4 다른 출처` 작은 링크. 펼치면 들여쓰기된 하위 행. |
| 마감 표식 | `D-3` 도장. D-3 이내 빨강 테두리, 지난 공고는 취소선. |
| 버튼 | 사각, 1px 잉크 테두리, 배경 없음. 주 동작만 잉크 채움(흰 글씨). 문구는 동사형 구체어: `수집 시작`, `이 구조로 저장`, `모두 읽음 처리`. |
| 입력 | 밑줄만 있는 입력(서식 기입란). 포커스 시 밑줄이 파랑 2px. |
| 상태 도장 | `정상` `주의` `실패` `정지` `링크`: 사각 테두리 + 작은 굵은 글자. 고무도장 느낌. |
| 단축키 표기 | `[j]` `[k]` 대괄호. |
| 트리 | 파일탐색기 들여쓰기 + `▸ ▾` 삼각형. 폴더 아이콘 없음(활자로만). 우측 끝 안읽음 수는 빨간 숫자. |

## 4.3 금지 요소 재확인

- **의도적으로 피한 AI 기본값**: 둥근 카드 그리드, 보라/파랑 그라데이션, 큰 썸네일 타일, 중앙 히어로, 3열 기능 소개, 원형 아바타, 이모지 아이콘, 부드러운 그림자, "Get Started" 류 문구.
- **개발자 금지 요소 반영**: 둥근 소셜 카드 → 괘선 목록으로 대체. 보라/파스텔 그라데이션 → 단색 종이·잉크 팔레트. 민트 버튼 → 잉크 테두리 사각 버튼.

## 4.4 화면/페이지 설계

| 화면 | 역할과 구조 | 핵심 인터랙션 |
|---|---|---|
| 메인 데스크 | 머리띠 + 3단. 좌측 특수 뷰(전체 새 글/키워드 알림/마감 임박/별표/주의 소스) → 카테고리 트리 → 태그. 중앙은 섹션 머리(현재 범위 이름을 굵게) + 도구줄(정렬, 안읽음만, 밀도) + 목록. 우측은 선택 항목의 교정지: 제목, 출처, 전체 필드 표, 발췌, 원문 열기 | `j/k` 이동 시 파란 커서 막대 이동, `m` 읽음 시 빨간 괘선 소멸 + 활자 바램, `Shift+A` 후 하단 "47건 읽음 처리 · 되돌리기" 띠 5초 |
| 소스 등록 | 좌: URL 입력 서식과 **분석 전보 로그**(단계별 한 줄씩 타자되듯 추가: `07:14:02 RSS 탐지 … 없음`). 우: 추출 미리보기 표(열 머리 = 필드, 편집 가능)와 제안 카테고리·태그 | 단계 완료마다 줄 끝에 `완료`/`없음` 도장 찍힘 |
| 소스 목록 | 전 폭 표. 상태 도장, 마지막 성공, 7일 신규(작은 막대), 주기 | 행 다중 선택 → 하단 일괄 작업 띠 |
| 소스 상세 | 머리: 소스명·URL·상태. 3구획: 필드 메타 표 / 명세 버전 이력 / 수집 실행 로그 | 버전 행 선택 시 명세 JSON 보기 |
| 카테고리 정리 | 좌: 트리(드래그 핸들 `⋮⋮`), 우: 선택 노드의 구독 목록 | 드롭 대상 위에 파란 삽입 괘선, 병합은 확인 대화상자 |
| 구조 조망 | 소스 × 필드역할 매트릭스. 칸에 필드명, 없으면 `·` | 열 머리 클릭 시 해당 필드를 가진 소스만 |
| 키워드 규칙 | 좌: 규칙 목록, 우: 편집기 + 최근 7일 매칭 미리보기 | 키워드 입력 즉시 매칭 건수 갱신 |
| 다이제스트 | 좌: 설정 서식, 우: 이메일 미리보기(신문 1면 축소판 레이아웃) | 설정 변경 시 미리보기 즉시 반영 |

**구현 우선순위**: 메인 데스크 → 소스 등록 → 키워드 규칙 → 다이제스트 → 소스 목록/상세 → 카테고리 정리 → 구조 조망

## 4.5 검증 질문

- **다른 프로젝트에 그대로 쓸 수 있는가?** 신문 판면·텔렉스·교정펜의 은유는 "새로 들어온 소식을 받아 판정하는" 이 서비스의 행위에서 나왔다. 쇼핑몰이나 SNS에 옮기면 의미를 잃는다. → 통과
- **금지 요소가 들어갔는가?** 둥근 모서리, 그라데이션, 카드, 히어로 없음. → 통과
- **디자인 지식 없이 구현 가능한가?** 색은 CSS 변수 11개, 폰트 1종(맑은 고딕), 반경 0, 괘선 1px 규칙만 지키면 된다. → 통과
